# LCKFB-TSPI-RK3566-Arcade-Console-board

An arcade console based on the LCKFB TaishanPi 1F-RK3566 development board.  
For more details, see: https://oshwhub.com/motozilog/project_dcqhpcgu

This version features **color PCB silk-screen printing** and is available in two themes:
- Arcade theme
- Console / Handheld theme

⚠️ **Note:** Boards have been manufactured only; they have **not yet been tested or verified**.
